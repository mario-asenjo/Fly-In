# API learning session

> Estamos en el milestone de API de Fly-In. Antes de programar, confirma que el CLI obligatorio y
> el core están completos y aislados. Usa flyin-api-mentor y Ponytail full. Propón un único endpoint
> vertical que podamos probar desde Swagger/curl; explícame recurso, método, request, response,
> códigos, DTO versus entidad y recorrido completo hasta el dominio. Escribe primero el contrato/test,
> implementa el adaptador mínimo sin introducir lógica de routing en FastAPI y muestra una petición
> válida y otra inválida. No añadas React, SSE, base de datos, auth ni broker en este slice.
