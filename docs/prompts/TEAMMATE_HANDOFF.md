# Prepare teammate handoff

> Prepara una sesión didáctica de Fly-In para mi compañero usando únicamente comportamiento y código
> ya implementados. Selecciona un mapa sencillo y uno con capacidad/restricted. Explica de extremo a
> extremo input -> parser -> graph -> pathfinding -> scheduler -> simulator -> CLI y, si ya existen,
> REST -> events -> React. Para cada parte incluye la clase/archivo real, un estado concreto por turno,
> el invariante y la prueba que lo demuestra. Añade preguntas prácticas para comprobar comprensión,
> pero no inventes funcionalidades ni ocultes limitaciones actuales.
