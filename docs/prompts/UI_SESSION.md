# UI session

> Trabaja solo en el slice UI aprobado de Fly-In. Verifica el contrato OpenAPI/API real y no dupliques
> lógica del simulador. Empieza por la proyección visual más pequeña que muestre el comportamiento,
> usa TypeScript strict, SVG/CSS/nativo antes de dependencias y cubre loading/error/accesibilidad
> relevantes. Prueba la transformación/reducer o interacción crítica, revisa el diff con Ponytail y
> actualiza progreso. No añadas WebSocket, gestor global de estado ni librería de grafos sin evidencia
> y ADR.
