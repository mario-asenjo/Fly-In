# Review a milestone

> Audita el milestone actual de Fly-In sin implementar nuevas features. Cruza el código con el
> subject 1.5, la hoja de evaluación, el contrato de dominio, Definition of Done y matriz de
> evaluación. Ejecuta evidencia fresca, valida los schedules independientemente, inspecciona
> dependencias/boundaries y usa /ponytail-audit para localizar sobreingeniería. Clasifica hallazgos
> por bloqueante, alto, medio o bajo; separa corrección de optimización y estilo. Actualiza progreso
> solo con hechos demostrados y propón el mínimo plan de cierre.
